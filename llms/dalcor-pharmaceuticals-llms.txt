# DalCor Pharmaceuticals

> DalCor Pharmaceuticals is a clinical-stage biopharmaceutical company (founded 2015, Montreal, with
> offices in Zug, Leatherhead and Sarasota) developing dalcetrapib, positioned as the first
> pharmacogenetic precision medicine in cardiovascular disease, for patients carrying the ADCY9
> rs1967309 AA genotype. DalCor runs no developer program and publishes no product API. The only
> machine-readable surface it exposes is the anonymously readable WordPress REST content API behind
> dalcorpharma.com, which serves the bilingual English/French corporate site.

## Read this first

- Send a normal browser **User-Agent**. The Cloudflare edge answers an absent or default User-Agent
  with HTTP 403 — including on the JSON routes.
- Discover routes at `https://dalcorpharma.com/wp-json/wp/v2`, **not** at `/wp-json/`. The root index
  is suppressed on this deployment and returns empty `namespaces` and `routes` arrays.
- Text fields are objects with a `rendered` HTML string (`title.rendered`, `content.rendered`).
  Strip HTML before use.
- Add `wpml_language=en` or `wpml_language=fr` to select the language edition.
- This is a corporate content surface, not a supported product. There is no documentation, no
  support channel, no SLA and no changelog for it.

## Key operations

- `listPosts` — `GET /wp-json/wp/v2/posts` — the press-release stream (24 EN, 6 FR).
- `listPages` — `GET /wp-json/wp/v2/pages` — the corporate and scientific site (17 EN, 15 FR).
- `getPage` — `GET /wp-json/wp/v2/pages/{id}` — e.g. 60 About DalCor, 75 Management, 110 Board of
  Directors, 135 Partners, 149 Dalcetrapib History, 154 Precision Medicine, 144 Cardiovascular
  Diseases, 159 Publications, 293 dal-GenE trial, 594 Dal-GenE-2 trial, 1260 DAL-302 study
  information for clinical trial sites.
- `search` — `GET /wp-json/wp/v2/search?search=…` — cross-content search.
- `listCategories` — `GET /wp-json/wp/v2/categories` — two terms; 13 is `press-releases`.
- `listMedia` — `GET /wp-json/wp/v2/media` — 54 attachments including congress poster assets.
